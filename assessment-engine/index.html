Shared architecture

How NAIB reads student progress

  1. Assessment core Attempt state, rendering, submission, completion, and exports.
  2. Scoring engine Objective scoring, exploratory signals, and manual-review evidence.
  3. Adaptive selector Constrained weighted selection without random grading.
  4. Storage engine Versioned local progress with reset and recovery support.
  5. Universal schemas Consistent items, assessments, attempts, and learner profiles.
  6. Problem-solving agent layer Reusable search, simulation, constraint, memory, explanation, and evidence services.

Khaemenes Academy · NAIB uses assessment evidence to understand progress and support instruction; assessment never defines the learner.
