# Verve N Veda → STOS Public Bridge

The GitHub Pages repository remains the public Verve N Veda front door. Public ecosystem navigation is centralized through `/stos/` instead of linking visitors directly to individual GitHub repositories.

The STOS public destination is configured in `assets/stos-public-config.js`. Set only the public HTTPS landing URL for the sovereign STOS Verve N Veda gateway. Do not place loopback addresses, filesystem paths, credentials, private service names, or internal network topology in this repository.

Until the public STOS HTTPS endpoint is commissioned, `/stos/` remains a safe handoff page and does not expose private STOS infrastructure.
