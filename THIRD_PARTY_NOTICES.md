# Third-Party Notices

This document records third-party resources that may be used by the Verve N Veda website.

Verve N Veda aims to use properly licensed, public-domain, original, or otherwise authorized materials. Any third-party code, fonts, icons, images, libraries, or embedded resources should be documented here when added.

The core website is intended to use standard HTML, CSS, and JavaScript.
