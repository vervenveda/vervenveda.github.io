What the module does:
- injects a Repository Architecture panel into the existing GitHub Intelligence view
- fetches the canonical ecosystem repository registry
- categorizes current repositories
- compares the current registry with the previous local snapshot
- reports added/removed/classification/manifest/account-family drift
- creates an attention queue
- exports report JSON
- refreshes automatically after 15 minutes when the admin portal is unlocked
- also refreshes after the existing Refresh GitHub button is used

It does NOT:
- change the administrator gate
- contain or alter a passcode
- change NAIB Internal Cloud
- rewrite repository source
- alter specialist routing
- expose hidden architecture
- delete or reclassify repositories at the source
