## Architecture boundaries
- Existing VNV handoff v1 is **source-provenance-only**: `SOURCE_PROVENANCE_REVIEW`. It does not accept any of the above repositories as an automatic caller.
- Academy Account Cloud receiving-side mirror checks the same v1 envelope offline. Neither side authenticates a live caller, authorizes writes, copies student data, or provides a protected route.
- Source/code projects stay owned by each repository; account records belong only to an approved protected Account Cloud service after T03 native commissioning.
- Any future enrollment/progress provider requires a separate contract, per-repository allowlist, exact source pin, reviewed field schema, learner/family authorization, replay and conflict controls, audit, rollback and explicit owner approval.
