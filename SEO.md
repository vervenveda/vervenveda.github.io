# SEO Strategy

## Objectives

- Fast-loading pages
- Semantic HTML
- HTTPS everywhere
- robots.txt
- XML sitemap
- Canonical URLs
- Open Graph metadata
- Descriptive page titles
- Meta descriptions
- Structured headings

## Search Console

- Verify domain property
- Submit sitemap
- Monitor indexing
- Resolve crawl issues

## Performance

Prioritize lightweight pages and minimize unnecessary external dependencies.
