## Acceptance tests prior to sovereign STOS migration

1. `?chrome_audit=1`: exactly one native 333 ticker, AutoPopulate ticker, native header, menu overlay, translator rail and universal dock. Menu CLOSED until triggered.
2. Stable geometry on desktop/tablet/mobile, including refresh, browser back/forward, reduced motion and zoom. No flashes, overlap or unexpected vertical shifts. **Still requires live browser verification** after the latest bootstrap/spacing changes.
3. All 6 hero links continue to route correctly. Account-based student routing remains a public navigation convenience, **not authorization**.
4. Sidebar, menu and toolbar interactions remain keyboard-operable; dialog focus is retained; no duplicated page-local headers.
5. Linguistics translator remains fully functional with local fallback if central resources are unavailable; no remote provider required for initial page render.
6. Directory cards, public indexes and slideshow preserve sanitized URL handling and public-only boundaries. Pause and preview remain functional.
7. Global CSS token normalization must not delete intentional responsive rules or animations. Minimum 16px for ordinary text/buttons, 7px corners, cream-on-charcoal contrast.
8. All GitHub Actions and page integrity tests pass **and** full rendered/browser testing passes. CI passing alone does not prove visual stability.
9. STOS terminal commissioning, NOEMA governance, account credentials and protected records remain independent. The public gateway contains no commissioning authority and cannot authorize protected execution.
10. Preserve a rollback source tree, hash manifest and validation receipts before changing repository ownership, runtime hosting or storage.

## Important deployment boundaries

- `vervenveda/vervenveda.github.io` is the current public presentation source. This codex does not claim that source snapshots are signed, sealed, copied into STOS or commissioned.
- The gateway currently contains browser-side local admin shortcut behavior; **this is not secure admin authentication**. Do not elevate or migrate it as privileged STOS identity.
- The repository's external origin references (GitHub Pages URLs, Linguistics asset URLs, public links) need explicit mapping and availability testing for offline-first sovereign hosting.
- The canonical VNV 333 ticker on the homepage is native markup and must remain distinct from the reusable `assets/vnv-333-ticker.js` implementation intended for other pages.
- The active slideshow comes from the inline controller; the standalone slideshow file is only an additional inventory item unless a separate consumer is verified.
- Versions are code snapshots, not proof of a sealed rollback or full browser parity. For authoritative future migration, update the codex only after new commits are independently verified.
