# Code of Conduct

## Our Commitment

Verve N Veda is committed to providing a welcoming, respectful, inclusive environment for everyone.

## Expected Behavior

- Be respectful and constructive.
- Welcome differing viewpoints.
- Focus on improving the project.
- Respect privacy and intellectual property.

## Unacceptable Behavior

- Harassment or discrimination.
- Personal attacks.
- Spam or malicious code.
- Publishing private information.
- Illegal or intentionally harmful activity.

## Enforcement

Project maintainers may edit, remove, or reject contributions that violate this Code of Conduct.
