# Verve N Veda SEO Metadata Installation

## Files

- `seo-head-snippet.html` — Copy into the `<head>` of `index.html`.
- `structured-data.html` — Copy into the `<head>` or immediately before `</body>`.
- `structured-data.json` — Reference copy of the JSON-LD data.

## Important image path

The social metadata expects this file:

`/images/vervenveda-social-card.jpg`

Recommended dimensions:

`1200 × 630 pixels`

Until that image exists, social platforms may not display a preview image.

## Avoid duplicates

Before pasting the snippet, remove or merge duplicate:

- `<title>`
- meta description
- canonical link
- Open Graph tags
- Twitter tags
- favicon links
- manifest links

Keep only one canonical URL and one description per page.

## Page-specific metadata

For every important interior page, customize:

- title
- description
- canonical URL
- Open Graph title
- Open Graph description
- Open Graph URL
- social image
- JSON-LD page name and URL
