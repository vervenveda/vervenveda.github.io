# Verve N Veda Country Gateway Standard

Version: 1.0  
Established: 2026-10-24

## Purpose

Country gateways are educational and diplomatic public-history portals within the Verve N Veda ecosystem. They share functional standards while preserving a distinct cultural identity for every country.

**Core principle:** shared functional standards, distinct cultural identities.

A new country site must not be a recolored copy of another country's design.

## 1. Required public architecture

Every country gateway should provide:

1. A documentary-led hero with a clearly identified country title and native-script name where applicable.
2. A native-language switch with complete parity for meaningful public content.
3. Correct writing direction, including RTL for Arabic, Persian and other RTL scripts.
4. Saved language preference using local browser storage only.
5. Land / geography orientation.
6. Regions, cities or cultural landscapes.
7. Culture and living heritage.
8. Historical timeline with source-linked claims.
9. Contemporary society / innovation / future-facing work.
10. Trusted sources and a repository source register.
11. A prominent **Free Khaemenes Academy** doorway.
12. A country-specific **Research Notebook / Academic Evidence** pathway where educational material is substantial enough to support student work.
13. World & Diplomacy links connecting the country site to the broader network.
14. Responsive mobile, desktop and print behavior.
15. Accessible navigation, controls, focus states and alt text.

## 2. Cultural identity standard

Design language should be derived from documented cultural forms rather than generic national-color theming.

Research may include:
- architecture;
- textile and weaving traditions;
- manuscript and calligraphic traditions;
- gardens and landscape design;
- ceramics, tilework and ornament;
- music and instruments;
- vernacular building materials;
- historic color traditions;
- regional craft traditions.

The design may abstract geometry, rhythm, proportion and palette. It should not copy protected artworks or falsely label invented motifs as traditional.

Examples already established:
- **Saudi Arabia:** Najdi architecture, Historic Jeddah/Roshan, Al-Qatt Al-Asiri, Al-Sadu.
- **Palestine:** limestone, olive landscapes, documentary archives, tatreez-informed stitch geometry.
- **Iran:** Persian Garden/Chahar Bagh geometry, turquoise/lapis, manuscript color, tile and carpet rhythm.

## 3. Photography and image provenance

Documentary images must be real photographs or archival scans.

For every displayed documentary image, record:
- place/subject;
- date or date range;
- creator/archive;
- source;
- license/public-domain status;
- contextual limitations.

Rules:
- No AI-generated or digitally illustrated image may stand in for a historical or documentary photograph.
- Illustrations are allowed only when explicitly labeled as illustrations.
- “Then / Now” comparisons must state whether camera positions actually match.
- Do not imply a photo was taken in the current year when it was not.
- Avoid duplicated carousel photographs unless duplication is intentional and disclosed.
- Prefer public domain, Creative Commons, museum/open-access and institutional archives.

## 4. Native-language parity

Language parity covers more than headings.

A complete implementation includes:
- headings and body copy;
- cards and timelines;
- dynamic carousel text;
- buttons and CTA labels;
- modal/dialog content;
- form labels and placeholders where present;
- image alt text when language-specific description is useful;
- ARIA labels and accessibility instructions;
- source descriptions;
- educational pathways;
- navigation and footer labels.

Native-language switching should:
- update document language;
- update document direction;
- persist preference locally;
- remain functional without external translation services.

Machine translation may assist drafting, but country-facing educational copy should be reviewed and corrected before it is treated as certified.

## 5. Facts, politics and diplomacy

Country gateways should distinguish:
- geography;
- population and communities;
- culture and identity;
- political authority;
- sovereignty;
- government claims;
- international-law findings;
- disputed interpretations.

For contemporary or contested claims:
- prefer primary or authoritative institutional evidence;
- date the claim or context;
- identify the issuing institution;
- distinguish findings from allegations or State Party submissions;
- avoid collective blame;
- do not treat an official source as the only description of a complex society;
- pair official material with credible independent or scholarly sources when appropriate.

## 6. Source placement

Evidence should remain close to consequential claims.

Each repository should maintain a `SOURCES.md` or equivalent source register containing:
- archival images;
- image licenses;
- historical primary sources;
- heritage records;
- major factual sources;
- current institutional sources;
- methodology notes for sensitive or disputed material.

## 7. Khaemenes Academy connection

Every mature country gateway should include a prominent path to:

**Free Khaemenes Academy Educational Platform**

Recommended education bridge:
- country-site learning doorway;
- Research Notebook / Academic Evidence packet;
- research question;
- source/citation fields;
- vocabulary and language connections;
- observations or notes;
- claim/reasoning/limitations;
- cross-subject reflection;
- parent/teacher review area;
- print/save capability.

Private student records must not be published by the country site.

## 8. Ecosystem registration

Every public country gateway should be registered in the main Verve N Veda **World & Diplomacy** directory.

Registration should include:
- country name;
- native-script name when applicable;
- canonical URL;
- repository URL;
- status;
- primary language(s);
- Academy connection status;
- source-register status.

Changes to the protected main `vervenveda/index.html` must remain surgical and should not alter its established design.

## 9. Accessibility and interaction baseline

Before certification:
- no duplicate IDs;
- no broken internal anchors;
- no malformed CSS units;
- all meaningful images have alt text;
- all new-tab links use `noopener`;
- all buttons have working handlers or valid native behavior;
- keyboard focus is visible;
- dialogs close by keyboard;
- carousels are keyboard operable;
- reduced-motion preferences are respected where animation exists;
- RTL layout does not reverse logical content incorrectly.

## 10. Release audit

A country gateway is ready for a release checkpoint only after:

- factual/source pass;
- image provenance pass;
- native-language parity pass;
- route/link pass;
- accessibility pass;
- mobile layout pass;
- JavaScript syntax pass;
- Academy doorway pass;
- World & Diplomacy registration check;
- source register update.

## 11. Growth model

Future country sites should begin with the shared standard but grow through country-specific research.

Suggested build order:
1. pre-audit repository;
2. research cultural design vocabulary;
3. establish sources and image rights;
4. build bilingual/native-language foundation;
5. create documentary landing page;
6. connect Academy pathway;
7. register in World & Diplomacy;
8. run forensic certification;
9. expand city, culture, history and innovation portals.

The standard is a floor, not a template. The visual result should make sense for the country being studied.
